# 英语主观题训练

考研英语二写作与翻译的侧边栏训练插件。

## 功能

- **7 个训练项目**：大作文第一、二、三段，小作文第一、二、三段，翻译。
- **题库**：2010—2023 年英语二小作文、大作文和翻译（2021—2023 为新增）+ AI 仿真题；也可以点击「AI 出题」现场生成一道新题。
- **图表**：所有图表类大作文都会在题目下方显示对应的柱状图、折线图、饼图或表格，数据与题目一致，颜色跟随主题自动适配。
- **分段训练**：选项目 → 选题目 → 写一段 → AI 按考研英语二评分标准批改。
- **选题与写作分开**：先在一个界面选题，进入写作后只显示题目、图表和输入区；想换题再点「换题」回到选题界面。
- **大字号、单列布局**：写作界面按“题目 → 输入 → 批改”纵向排列，减少左右分栏和视觉噪音。
- **批改内容**：固定四部分——① 判分点与优点；② 问题句与修改建议（含修改示例）；③ 可复用逻辑与句式（按“动态数据大幅变化”“两个数据对比明显”等场景分类）；④ 参考修改文。
- **空格宽容**：不因多一个/少一个空格、标点前后空格、换行、缩进扣分或提出意见；只有空格导致单词粘连或拼写错误时才处理。
- **图片添加题目**：在选题界面点「上传图片添加题目」，AI 识别图片中的题干/图表/翻译原文，自动整理成题目并加入题库，识别后直接进入写作。
- **自由训练**：不限顺序、不设通关门槛；每次批改后可以换题继续，也可以反复重写同一题。
- **综合检验**：大作文整篇、小作文整篇、翻译整篇都可以直接开始，不需要先完成分段训练。
- **记录**：本地保存每次作答原文、AI 建议、修改示范、可复用句式和整篇检验结果。
- **草稿恢复**：写作中的作文、批改结果和当前界面会自动保存；切换侧边栏页面再回来不会丢失。

## 使用

1. 左侧栏点击「英语主观题训练」图标。
2. 在「训练」里选一个项目。默认先用真题；也可以切到「AI 题」、点「AI 出题」，或上传题目图片让 AI 识别后加入题库。
3. 写完本段后点「提交 AI 批改」，或按 `Ctrl + Enter`。
4. 看批改里的四个部分：判分点与优点、问题句与修改建议、可复用逻辑与句式、参考修改文；然后点「换一题继续」，或继续重写本题。
5. 想检验整篇时直接切到「综合检验」，选大作文、小作文或翻译即可开始。

## 评分口径

- 分段训练：写作段 10 分制，高分线 8 分；翻译分段 15 分制，高分线 12 分。
- 大作文整篇：15 分制，高分线 12 分。
- 小作文整篇：10 分制，高分线 8 分。
- 翻译整篇：15 分制，高分线 12 分。

AI 批改使用当前 Profile 默认模型（`agent-default-model`）。如果模型暂时不可用，面板会降级为本地规则诊断，并在结果上标注「本地诊断」；本地分数只作参考。

## 数据

训练进度保存在宿主侧的文件里：`$DSH_HOME/english-writing-state.json`（默认 `~/.dsh/english-writing-state.json`）。同一台机器上的桌面窗口、手机浏览器、远程访问入口（局域网 / 隧道 / Tailscale）读写的是**同一份记录**，换网址或换设备都不会丢。

浏览器 `localStorage`（`dsh.english-writing.v1`）只作为离线缓存：宿主不可达时本轮照常可用，网络恢复后自动补写。加载时按 `updatedAt` 取较新的一侧——所以升级到本版本时，旧版本留在 localStorage 里的记录会被自动搬进宿主文件。

在「记录」里点「清空全部记录」会清空这份文件，也会清掉浏览器缓存。多台设备**同时**开着改同一份记录时以最后保存的为准（切回窗口时面板会先拉一次较新的版本再让你继续写）。

## 文件

- `index.js`：Host 半，注册 `/english-writing/evaluate`（批改 / AI 出题）和 `/english-writing/state`（读取 / 保存训练记录）两个路由，调用 `ctx.llm`。
- `client.js`：Client 半，注册 `sidebar.panellist` 和 `main` 面板。
- `cordis.patch.yml`：bundle patch。
- `locale/*.json`：插件管理页的标题和描述。
- `icon.svg`：插件图标。
